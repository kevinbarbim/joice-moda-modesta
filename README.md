# Joice Moda Modesta

Landing page da Joice Moda Modesta, desenvolvida com React, TypeScript, Vite e Tailwind CSS.

Domínio: [joicemodamodesta.tech](https://joicemodamodesta.tech)

## Executar localmente

Requisitos: Node.js 20.19+ ou 22.12+ e npm.

```bash
npm install
npm run dev
```

## Gerar o build

```bash
npm run typecheck
npm run lint
npm run build
npm run preview
```

O conteúdo editável está centralizado em `src/data/site.ts` e as imagens ficam em `public/images`.
